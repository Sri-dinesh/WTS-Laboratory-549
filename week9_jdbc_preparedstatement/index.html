CRUD using PreparedStatement

Create a product table with product number, name, image, and price, then perform insert, retrieve, update, and delete operations using parameterized JDBC queries.

Pre-Lab Questions

  • Purpose of Prepared and Callable Statement
  • Steps to create a Prepared Statement
  • Steps to create a Callable Statement
  • Stored procedure and stored function
  • Difference between procedure and function

Database Theme

Uses the same MariaDB credentials as the previous JDBC labs.

URL: jdbc:mariadb://localhost:3306/jdbc_demo
User: eremika
Driver: org.mariadb.jdbc.Driver

Programs

9(i) CreateTablePrepared.java Create

Creates the products table in MariaDB.

9(ii) InsertTablePrepared.java Insert

Inserts product records using placeholders and BLOB image data.

9(iii) GetTablePrepared.java Read

Retrieves all product rows from the table.

9(iv) UpdateTablePrepared.java Update

Updates the price for a selected product number.

9(v) DeleteTablePrepared.java Delete

Deletes a product record by product number.
