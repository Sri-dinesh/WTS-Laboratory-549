# Experiment 12: Session and Cookie Management

Open `/experiment12_state_management/state` through Tomcat. Refresh the page to see the session visit count and the persistent cookie visit count change independently.

Compile `src/StateManagementServlet.java` into `WEB-INF/classes` with the Servlet API JAR, copy the application to Tomcat's `webapps` directory, and start Tomcat.

This experiment uses HTTP sessions and cookies only; it does not require a database connection or JDBC driver.
